## 🆘 Troubleshooting

### Si los Generadores No Responden:
1. Verifica que el banner DEMO esté visible
2. Revisa la consola del navegador (F12)
3. El modo DEMO siempre funciona offline

### Si Quieres Resultados Reales Ahora:
1. Espera 5-10 minutos más
2. El backend está compilando
3. Verificación automática cada 30 segundos
4. Recarga la página manualmente si prefieres

### Si el Banner No Desaparece Después de 15 Min:
1. Revisa que Java esté corriendo: `Get-Process java`
2. Verifica logs en ventana CMD abierta
3. Prueba manualmente: http://localhost:8080/api/health
4. Si falla, reinicia: cierra CMD y ejecuta `.\run-local.bat`

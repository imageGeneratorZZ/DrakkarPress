🔗 Arquitectura de Integración

🔄

Flujo: Libro Físico

Desde el manuscrito hasta la puerta del lector sin inventario ni riesgo.

  • 1. Autor sube PDF a DrakkarPress
  • 2. IA genera portada 2550x3300px (specs Lulu)
  • 3. Lector compra via Shopify
  • 4. Webhook envía orden a Lulu API
  • 5. Lulu imprime y envía directo
  • 6. Tracking sync vía webhooks
  • 7. Royalties calculados automáticamente
📱

Flujo: eBook + Amazon

Distribución dual: DrakkarPress directo + alcance masivo de Amazon.

  • 1. Autor sube EPUB/MOBI
  • 2. IA optimiza metadata para SEO
  • 3. Publicación dual: DrakkarPress + KDP
  • 4. Venta en DrakkarPress: 90% autor
  • 5. Venta en Amazon: 70% autor (KDP)
  • 6. Sincronización de precios
  • 7. Unified dashboard para ambos canales
🤖

IA + Lulu Integration

La IA generadora trabaja con las especificaciones exactas de Lulu para producción perfecta.

  • Portadas en dimensiones Lulu (2550x3300px @ 300dpi)
  • Spine width calculado automáticamente
  • Color profile: CMYK para impresión
  • Bleed de 0.125" incluido
  • Preview 3D del libro final
  • Validación de specs antes de enviar

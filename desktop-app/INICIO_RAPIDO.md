# 🚀 INICIO RÁPIDO - DrakkarPress Desktop

## Para Iniciar la App AHORA:

```powershell
cd c:\Users\SuperUsuario\DrakkarPress.com\desktop-app
npm run dev
```

## Lo Que Verás:

1. **Se abrirá una ventana** de 1400x900px
2. **Dashboard principal** con estadísticas
3. **Sidebar izquierdo** con navegación:
   - 🏠 Dashboard
   - ✨ Generadores (8 tipos)
   - 📚 Mi Biblioteca
   - 🏪 Mi Tienda
   - ⚙️ Configuración
4. **Badge de estado** (arriba derecha):
   - 🟢 Conectado (si backend está activo)
   - 🟠 Modo Offline (si backend no está disponible)

## Prueba Esto:

### 1. Generar Contenido
- Click en **"Generadores"**
- Selecciona **"Generar Idea de Libro"**
- Escribe: "Una historia de fantasía épica"
- Click **"Generar"**
- Verás resultado DEMO (si backend no está activo)

### 2. Ver Biblioteca
- Click en **"Mi Biblioteca"**
- Verás la creación guardada
- Prueba la búsqueda escribiendo algo
- Click en ⭐ para marcar como favorito

### 3. Configuración
- Click en **"Configuración"**
- Cambia el tema
- Cambia el idioma
- Modifica opciones de IA

## Para Compilar EXE:

```powershell
npm run build:win
```

El instalador estará en: `release/DrakkarPress-Setup-1.0.0.exe`

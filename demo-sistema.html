🔄 Flujo de Trabajo Completo

1

Crear Proyecto

Ingresa título, género, estilo, número de capítulos y sinopsis del libro que quieres crear.

2

Generar Estructura (Outline)

La IA genera automáticamente títulos para cada capítulo basándose en tu sinopsis. Toma 10-20 segundos.

3

Escribir Libro Completo

Click en "Escribir Libro Completo" y la IA genera todos los capítulos secuencialmente con coherencia narrativa. Tiempo: 2-15 minutos dependiendo de la IA.

4

Editar Capítulo

Click en "Editar" en cualquier capítulo. Modifica el contenido (ej: cambia nombres, eventos, diálogos). Al guardar, los capítulos posteriores se marcan en 🟠 naranja.

5

Regenerar en Cascada

Click en "🔄 Cascada" y la IA regenera todos los capítulos posteriores manteniendo coherencia con tus ediciones.

6

Exportar Libro

Click en "💾 Exportar Libro" para descargar un archivo .txt con el libro completo formateado.

@Transactional
public List<BookChapter> regenerateCascade(UUID projectId, int fromChapter) {
    BookProject project = projectRepository.findById(projectId)
            .orElseThrow(() -> new IllegalArgumentException("Proyecto no encontrado"));
    
    List<BookChapter> regenerated = new ArrayList<>();
    
    // Regenerar todos los capítulos posteriores
    for (int i = fromChapter + 1; i <= project.getPlannedChapters(); i++) {
        try {
            BookChapter chapter = chapterRepository
                .findByProjectAndChapterOrder(project, i)
                .orElse(null);
            
            if (chapter != null && chapter.getContent() != null) {
                // Construir contexto de capítulos previos
                String context = buildPreviousContext(project, i);
                
                // Regenerar con contexto actualizado
                BookChapter regen = regenerateChapter(projectId, i);
                regenerated.add(regen);
            }
        } catch (Exception e) {
            log.error("Error regenerando capítulo {}: {}", i, e.getMessage());
            break; // Detener cascada si hay error
        }
    }
    
    return regenerated;
}

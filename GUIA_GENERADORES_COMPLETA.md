## 🔥 MEDIDOR DE EROTISMO (6 Niveles)

### Nivel 0: 😊 Limpio
- **Contenido**: Sin referencias sexuales
- **Ejemplo**: "Sus manos se rozaron brevemente"
- **Público**: Todos los públicos

### Nivel 1: 😉 Sugerente
- **Contenido**: Insinuaciones sutiles, tensión sexual
- **Ejemplo**: "La forma en que la miraba decía más que mil palabras"
- **Público**: 13+

### Nivel 2: 😏 Sensual
- **Contenido**: Besos apasionados, caricias descriptivas
- **Ejemplo**: "Sus labios recorrieron lentamente su cuello"
- **Público**: 16+

### Nivel 3: 🔥 Caliente
- **Contenido**: Escenas sexuales sugeridas, detalles moderados
- **Ejemplo**: "La ropa cayó al suelo mientras sus cuerpos se entrelazaban"
- **Público**: 18+

### Nivel 4: 💋 Explícito
- **Contenido**: Escenas sexuales detalladas y explícitas
- **Ejemplo**: Descripciones completas de actos sexuales
- **Público**: Solo adultos

### Nivel 5: 🔞 XXX
- **Contenido**: Contenido adulto extremo sin censura
- **Ejemplo**: Todo sin límites ni tabúes
- **Público**: Contenido para adultos advertido

- **7 Tonos**: Neutral, romántico, erótico, tenso, cómico, dramático, misterioso

- **6 Enfoques**: General, gramática, estilo, claridad, descriptivo, conciso

### 🔍 Analizar Estilo

## 💡 CASOS DE USO REALES

### Para Autores de Ficción
1. Usa ecualizador para crear mezcla única
2. Ajusta nivel erotismo según audiencia
3. Genera idea base
4. Crea personajes principales
5. Genera títulos atractivos
6. Usa "Extender Capítulo" cuando bloqueas
7. Mejora texto final con IA

### Para Escritores No Ficción
1. Selecciona tipo de informe/documento
2. Define audiencia objetivo
3. Genera estructura base
4. Usa "Mejorar Texto" para pulir
5. Analiza estilo para consistencia

### Para Autores de Cocina
1. Define tipo de recetas
2. Selecciona dificultad y tiempos
3. Especifica estilo culinario
4. Genera recetas completas con:
   - Ingredientes
   - Instrucciones paso a paso
   - Tips profesionales
   - Variaciones

### Para Autores Técnicos/Académicos
1. Selecciona tipo documento técnico
2. Define nivel de complejidad
3. Especifica audiencia
4. Genera estructura y contenido
5. Revisa con análisis de estilo

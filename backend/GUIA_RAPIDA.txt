╚══════════════════════════════════════════════════════════════════════════════╝

JAVA 21:
--------
1. Descarga desde: https://adoptium.net/temurin/releases/?version=21
2. Descarga el instalador .msi para Windows x64
3. Ejecuta el instalador
4. Marca la opción "Add to PATH"
5. Completa la instalación

MAVEN:
------
1. Descarga desde: https://maven.apache.org/download.cgi
2. Descarga el archivo "Binary zip archive"
3. Descomprime en: C:\Program Files\apache-maven
4. Agregar a PATH:
   a. Busca "Variables de entorno del sistema" en Windows
   b. Click en "Variables de entorno"
   c. En "Variables del sistema", busca "Path" y edítala
   d. Agrega: C:\Program Files\apache-maven\bin
   e. Click OK en todas las ventanas

5. REINICIA PowerShell

VERIFICAR:
----------
java -version     # Debe mostrar: openjdk version "21.x.x"
mvn -version      # Debe mostrar: Apache Maven 3.x.x

╚══════════════════════════════════════════════════════════════════════════════╝

ERROR: "mvn no se reconoce"
---------------------------
• Maven no está instalado o no está en PATH
• Solución: Instala Maven y reinicia PowerShell

ERROR: "Connection refused"
---------------------------
• PostgreSQL no está corriendo
• Solución: docker-compose up -d

ERROR: "Port 8080 already in use"
---------------------------------
• Otro servicio usa el puerto 8080
• Solución 1: Detén el otro servicio
• Solución 2: Cambia el puerto en .env: PORT=8081

ERROR: Java version incompatible
---------------------------------
• Necesitas Java 21 o superior
• Solución: Instala Java 21 desde adoptium.net
